What to notice

    02 / VERIFY INDEPENDENTLY

    Don’t use contact details from the message you’re checking. If it asks for money, passwords, or a verification code, pause first.

    What this check can—and can’t—tell you

    This is a lexical check: it looks at the text and structure of the link. It does not open the page, follow redirects, check reputation lists, verify ownership, or determine whether the content is malicious. HTTPS protects a connection; it does not prove a site is trustworthy.

    Built on this project’s lexical-feature research, not a running machine-learning model. The README reports a 5.45% false-positive rate for its Random Forest on its research test set; that is not a measured error rate for this checker. Both false alarms and missed threats are possible.
