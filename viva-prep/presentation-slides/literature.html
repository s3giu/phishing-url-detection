Literature Overview & Research Gap
Three Generations of Phishing Detection
GENERATION 1
Blacklisting
Fast lookup — milliseconds
Simple to implement
Fails on zero-hour attacks
Requires constant manual updates
Reactive, not predictive
e.g. Google Safe Browsing
GENERATION 2
Content-Based ML
High accuracy possible
Detects new URLs
Requires page loading — slow
DNS + WHOIS + HTML needed
Privacy concerns; API costs
e.g. Rao & Pais (2020)
THIS STUDY — GENERATION 3
Lexical-Only ML
Real-time — under 1ms per URL
No external API calls needed
Privacy-preserving
Detects zero-hour attacks
Fully reproducible pipeline
e.g. Sahingoz et al. (2019) + this work
Research Gap Identified — Three Missing Elements in Literature
01
No controlled comparison of purely lexical classifiers on a large-scale modern dataset (>600K URLs)
02
FPR rarely reported — critical for user experience, yet absent from most published studies
03
No open-source reproducible pipeline with working web prototype demonstrating real-world viability
