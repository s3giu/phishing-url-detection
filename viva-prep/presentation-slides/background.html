Research Aim & Background
Scale of the Problem
651,191
URLs analysed in this study — one of the largest lexical-only datasets in published research
#1
Phishing remains the most prevalent cyber threat — APWG recorded record attack volumes in 2022 (APWG, 2024)
0ms
Time blacklists take to detect a zero-hour phishing URL — they simply cannot. ML can.
Research Question
"Can machine learning models using only lexical URL features detect phishing URLs accurately enough for real-world deployment, and which classifier performs best?"
Research Aim
To design, implement, and evaluate a lexical-feature-based machine learning pipeline that classifies URLs as benign or malicious in real time — without external API calls, DNS lookups, or page content analysis.
Why This Matters
Blacklists fail on zero-hour attacks — new URLs not yet catalogued
Content-based ML requires page loading — too slow for real-time use
Lexical-only ML analyses the URL string alone — instant, private, scalable
